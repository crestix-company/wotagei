一般社団法人ヲタ芸普及協会 WordPress Theme
==========================================

概要
----
一般社団法人ヲタ芸普及協会の公式サイト用オリジナルテーマです。Lumièreは協会所属の公式パフォーマンスチームとして紹介しています。
Googleスプレッドシート、追加のGoogleドキュメント、既存サイト、2つのGoogle Drive素材フォルダを基に制作しています。

構成番号とページ
----------------
トップページから次の10項目へ、それぞれ独立して移動できます（構成案の08は削除済み）。
01. ヲタ芸普及協会について
02. メンバー・所属チーム
03. 出演情報・お知らせ
04. これまでの実績
05. 出演依頼・お仕事のご相談
06. スクール・講師派遣
07. スポンサー募集
09. オンラインショップ（指定の既存サイトへ移動）
10. Lumière 公式ページ
11. 日記

このほか、お問い合わせ等の補助ページがあります。

導入方法
--------
1. 現在の本番サイトを必ずバックアップしてください。
2. 可能であれば本番と同じ環境のステージングサイトを作成してください。
3. WordPress管理画面の「外観」→「テーマ」→「新規追加」→「テーマのアップロード」から、このZIPをそのままアップロードします。
4. テーマを有効化すると必要な固定ページが自動作成されます。
5. 「設定」→「パーマリンク」を開き、変更せずに「変更を保存」を1回押します。
6. 「外観」→「カスタマイズ」→「ヲタ芸普及協会 連絡先・SNS」で、メール・電話・LINE・各SNSのURLを確認します。
7. 表示とフォーム送信をステージングサイトで確認した後、アクセスの少ない時間帯に本番へ切り替えます。

更新できる内容
--------------
- 通常の「投稿」：お知らせ、活動レポート
- 「出演情報」：開催日、地域、詳細URL
- 「活動実績」：年、カテゴリ、YouTube URL
- 「動画ギャラリー」：YouTube URL、公開時期、イベント名、コラボ先
- 「メンバー」：名前、英字表記、役割、写真、表示順
- 各ページの本文・見出しを変更する場合はテーマテンプレートの編集が必要です

オンラインストア
----------------
構成番号09は https://lumiere-woodbell.com/#company へ直接移動します。

お問い合わせフォーム
--------------------
フォームはWordPress標準のメール送信機能を利用し、初期設定では otagei.fukyuu@gmail.com に送信します。
サーバー環境によってはメール到達率向上のためSMTP設定が必要です。公開前に必ず実送信テストを行ってください。

公開前チェック
--------------
- PC / タブレット / スマートフォンの表示
- LINE、電話、メール、Instagram、YouTube、Xのリンク
- お問い合わせフォームの送信と受信
- 出演情報の日付と公開範囲
- YouTube動画の再生
- 商品購入・決済・送料設定（WooCommerce利用時）
- 写真・ロゴ・出演者画像の掲載許諾
- 旧サイトのURL、検索順位、計測タグを引き継ぐ場合の設定

安全な切り替えについて
----------------------
本番へ直接上書きせず、ステージングで最終確認後に切り替えてください。旧テーマとデータベースのバックアップを保持し、問題があればすぐ戻せる状態で作業することを推奨します。

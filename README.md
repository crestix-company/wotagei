# 一般社団法人ヲタ芸普及協会 公式サイト

一般社団法人ヲタ芸普及協会を主役に据えた公式サイトです。協会公式パフォーマンスチーム「Lumière」の活動、出演情報、実績、スクール、スポンサー募集などを掲載します。

このリポジトリには、デザイン確認用のWebアプリと、本番のWordPressへ導入するオリジナルテーマを収録しています。

## 構成

- `app/`：ローカル確認用Webサイト
- `public/`：ロゴ、写真、動画などの確認用素材
- `wordpress-theme/lumiere/`：WordPressへ導入する完成テーマ

## ローカル確認

Node.js 22.13以降を使用します。

```bash
npm install
npm run dev
```

通常は `http://localhost:3001/` で確認できます。

品質確認：

```bash
npm run lint
npm run build
```

## WordPressへの導入

1. `wordpress-theme/lumiere` フォルダをZIP圧縮します。
2. WordPress管理画面の「外観」→「テーマ」→「新規追加」→「テーマのアップロード」を開きます。
3. ZIPをアップロードしてテーマを有効化します。
4. 「設定」→「パーマリンク」を開き、「変更を保存」を一度実行します。
5. 「外観」→「カスタマイズ」→「ヲタ芸普及協会 連絡先・SNS」で連絡先を確認します。

テーマ有効化時に必要な固定ページが自動作成されます。投稿、出演情報、活動実績、動画、メンバーはWordPress管理画面から更新できます。

お問い合わせの初期送信先は `otagei.fukyuu@gmail.com` です。公開前にWordPress側の登録アドレスとフォームの実送信を確認してください。
